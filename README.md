# Job Hunt Command Center — Published Site

Public GitHub Pages repository for Alvin's Job Hunt Command Center.

This repository intentionally contains only the site shell and an encrypted data payload. The readable canonical job-search data remains in the private `ACPOmega/job-hunt-command-center` repository.

`site/data/job-data.enc.json` is generated by the `Publish encrypted dashboard` workflow in the private repo whenever its data changes. Don't edit it by hand. Structural changes to both repos are logged in the private repo's `AI-CHANGELOG.md`.

Material buttons open the private GitHub library (sign-in and repo access required). Role details let the user save an intended resume and personal notes as browser-local encrypted records keyed by r-id. Submitted mappings remain canonical. Export data includes a separate browser-local backup; store that downloaded plaintext privately. Browser storage, dashboard key rotation, and moving devices/origins can affect local edits; there is no repo writeback.
